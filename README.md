# Финт с триггером измерительного интервала для восьмипинового v003j4m6:<br>
Первый таймер-счетчик управляется внутренним триггером второго таймера как обычно. Второй таймер формирует триггер по cвоему первому каналу сравнения и прерывание по своему второму каналу. Второй канал настраивается, например, на 10 тактов таймера. Первый - на 100. Перегрузка - на 1100. Таким образом имеем триггер 1000 тактов и 90 тактов на чтение счетчика. Обработка и вывод как обычно.<br>
